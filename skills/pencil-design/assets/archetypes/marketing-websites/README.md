# marketing-websites

Public-facing surfaces: home pages, pricing, feature pages, launch campaigns. The buyer is the audience; conversion is the job.

## Archetypes in this folder

- **conversion-focused-saas.md**, Linear (primary) / Stripe / Vercel. Monumental confident design where the marketing IS product-caliber. Numbered systematic sections, dark-mode default, product screenshots as content, philosophical Method pages.
- **editorial-storytelling.md**, Linear Method (manifesto flavour) / Apple product pages (cinematic flavour) / Tesla. Long-form narrative surfaces; chrome disappears and the content carries the reader through a single arc.

## Planned archetypes (coming in v2.x)

- **playful-brand-led.md**, Mailbrew / friendly DTC. Warm, conversational, illustrated, restrained colour pop.
- **brutalist-statement.md**, Vercel brutalism era / fashion brands. Aggressive type, raw layout, statement-first.
- **premium-luxury.md**, Aesop / Apple. Refined, materially deliberate, generous whitespace.
- **developer-technical.md**, Supabase / Resend / Linear's developer pages. Code-as-content, technical credibility leads, dense product sections.

## Picking between them

| User cue | Archetype |
|---|---|
| "Modern SaaS / dev tool / AI product marketing" | conversion-focused-saas |
| "Single-product launch / methodology page / manifesto" | editorial-storytelling |
| (other archetypes coming v2.x) | |

If the brief is generic ("build a marketing site"), default to **conversion-focused-saas** for the SaaS / B2B / dev-tool case.

## Status

This folder is partially populated in v2.0.0 (2 of 6). Pencil's `get_guidelines("style", ...)` covers ~28 landing-page styles at a *visual* level; these archetypes operate at a complementary *strategy* level (surface intent, conversion shape, content hierarchy).
