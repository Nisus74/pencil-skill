# e-commerce-content

Commerce and content-publishing surfaces. The product or article is the centre; chrome should not compete with it.

## Planned archetypes (coming in v2.x)

- **premium-dtc.md**, Glossier / Aesop. Image and type emphasis, premium tone, generous whitespace, restrained colour.
- **marketplace-dense.md**, Amazon / Depop. Product grids, scarcity cues, data-heavy listings, conversion above polish.
- **content-publishing.md**, Substack / Medium. Type-led, reading-optimised, light chrome, byline emphasis.

## Status

This folder ships empty in v2.0.0. Populated archetypes land in v2.x.
