# ai-products

Surfaces for AI-native products: chat, agent execution, spatial / canvas tools, AI-augmented workspaces. These differ from standard SaaS because the AI is a participant in the UI, not a feature buried in a menu.

## Archetypes in this folder

- **conversation-chat.md**, Claude / ChatGPT. Conversation-first, chrome-light, type-led, generous whitespace around messages.
- **agent-execution.md**, Devin / Claude Code / agent monitors. Live task lists, streaming state, progress as primary content.
- **canvas-spatial.md**, Spline / Vision Pro UI. Depth, gradients, 3D affordances, glassy materials.
- **ai-augmented-workspace.md**, Notion AI / Cursor / Granola. Familiar workspace shells with AI surfacing inline; the AI is contextual, not modal.

## Picking between them

| User cue | Archetype |
|---|---|
| "Chat with an AI / chatbot / assistant" | conversation-chat |
| "Agent doing work / autonomous task / live execution" | agent-execution |
| "3D / spatial / depth / Vision Pro" | canvas-spatial |
| "AI inside an existing app surface" | ai-augmented-workspace |

The AI-product space moves fast. Treat these archetypes as accurate to early-2026; per-session references are especially valuable here because the visual conventions are still settling.
