# docs-onboarding

Documentation surfaces and first-run experiences. The user has just arrived; clarity and progression matter more than personality.

## Planned archetypes (coming in v2.x)

- **product-docs.md**, Stripe docs / Vercel docs. Three-column layout (nav / content / on-this-page), code-as-content.
- **api-reference.md**, Stripe API ref / Supabase. Side-by-side request and response, language switcher, dense parameter tables.
- **onboarding-flow.md**, Welcome experiences. Step-aware progression, single decision per screen, success states with next-action prompts.

## Status

This folder ships empty in v2.0.0. Populated archetypes land in v2.x.
