# editors-creative-tools

Surfaces for editors, IDEs, design tools, writing tools, anywhere the user creates rather than consumes. Density is high, panels and palettes lead, the canvas or document is the focal point.

## Planned archetypes (coming in v2.x)

- **canvas-design.md**, Figma / Sketch. Floating tools, contextual UI, infinite canvas as the centre.
- **code-editor.md**, VS Code / Cursor. Mono everywhere, dark surface default, panel-heavy.
- **writing-minimal.md**, iA Writer / Bear. Distraction-free, single column, type as the interface.
- **data-tool.md**, Mode / Hex / Observable. Notebook plus query plus chart, dense panels with handoff between modes.
- **command-driven.md**, Raycast / Linear command bar. Keyboard-first, palette-centric, minimal chrome.

## Status

This folder ships empty in v2.0.0. Populated archetypes land in v2.x.
