# saas-apps/b2b

Products sold to other businesses for internal use. Most live behind login. The user spends hours per day inside; the chrome should disappear, the data and workflows should lead.

## Archetypes in this folder

- **analytics-dashboard.md**, Mixpanel / Amplitude / PostHog. Data-led overview surfaces. Mono numerals, hairline borders, no shadows.
- **enterprise-corporate.md**, Salesforce / ServiceNow. Trustworthy, dense, conservative. Heavy use of tabs and side-rails. Users work here all day.
- **modern-pro-tool.md**, Linear / Notion biz. Refined-dense; the new generation of B2B that feels designed by people who use it.
- **workflow-platform.md**, Asana / Monday. Colourful collaborative; status as colour signal; many small interactive cards.

## Picking between them

| User cue | Archetype |
|---|---|
| "Show me usage / metrics / events" | analytics-dashboard |
| "Internal admin / records / system of record" | enterprise-corporate |
| "Modern productivity tool, opinionated software" | modern-pro-tool |
| "Project / task management with collaborators" | workflow-platform |

If the brief is generic ("build a SaaS dashboard") and the user supplied no direction, default to **modern-pro-tool** for the broad case or **analytics-dashboard** when KPIs and charts dominate the brief.
