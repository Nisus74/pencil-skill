# saas-apps/b2c

Consumer-facing SaaS products. The user is an individual paying with their own money or attention. Surfaces feel softer, copy is conversational, the brand has more visual weight than in B2B.

## Archetypes in this folder

- **consumer-productivity.md**, Notion personal / Things. Soft document feel, restrained colour, type-led.
- **consumer-finance.md**, Cash App / Revolut. Playful, confident, single bold accent, large numerals as art.
- **consumer-social.md**, Discord / Twitter. Feed-first, chrome-light, fast-scrolling, status everywhere.
- **consumer-media.md**, Spotify / Netflix. Content-first immersive, full-bleed imagery, dark surfaces by default.

## Picking between them

| User cue | Archetype |
|---|---|
| "Personal productivity / notes / planning" | consumer-productivity |
| "Money / payments / wallet / investment" | consumer-finance |
| "Community / messaging / feed / posts" | consumer-social |
| "Music / video / podcasts / streaming" | consumer-media |

Defaulting when the brief is silent: **consumer-productivity** is the safest fallback for "build a consumer app" because its restraint adapts well; the other three carry stronger personality and need a stronger brief to land right.
