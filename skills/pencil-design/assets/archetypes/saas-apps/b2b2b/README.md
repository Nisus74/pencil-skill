# saas-apps/b2b2b

Developer-facing platforms and infrastructure tooling. The buyer is an engineer; technical credibility leads. Density is high, terminology is precise, examples are first-class citizens.

## Planned archetypes (coming in v2.x)

- **developer-platform.md**, Stripe / Twilio. Technical, trustworthy, dense documentation embedded in the product surface itself.
- **infrastructure-monitoring.md**, Datadog / New Relic. Dense status panels, time-series everywhere, alerts as primary entities.
- **api-developer-tools.md**, Postman / Insomnia. Utility-led, panel-heavy, request / response as the central pattern.

## Status

This folder ships empty in v2.0.0. Populated archetypes land in v2.x as references accumulate. To request priority, drop screenshots / notes in a session and we can graduate the per-session ephemeral into a shipped file.
