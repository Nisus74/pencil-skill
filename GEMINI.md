# Pencil.dev Design Skill

This project provides the `pencil-design` skill for working with pencil.dev design files.

Use the `activate_skill` tool to load the `pencil-design` skill when working with
pencil.dev `.pen` files or the Pencil MCP server.

For Gemini-specific tool name mappings, see `skills/pencil-design/references/gemini-tools.md`.
